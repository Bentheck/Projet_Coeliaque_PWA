# Frontend client

This folder contains the React, TypeScript, and Vite Progressive Web App for Service Coeliaque.

For the full project overview, architecture, local setup, configuration, and backend test instructions, see the [repository README](../README.md).

## Frontend commands

Run these commands from this folder:

```bash
npm ci
npm run dev
```

Other available scripts:

```bash
npm run lint
npm run build
npm run build:prerender
npm run preview
```
